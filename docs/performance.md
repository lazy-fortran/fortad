# Performance

Benchmarks are kept in the separate
[fortad-bench](https://github.com/lazy-fortran/fortad-bench) repository, together
with the compiler, hardware, flags, raw output and an independent correctness check
for each measurement.

On the recorded `dot_sin` workload, code generated by fortad is about 8% faster than
Enzyme for one forward direction, about ten times faster per direction at sixteen
forward directions, 1.7 to 1.8 times faster for the fused reverse reduction, and 2.1
to 2.2 times faster for the element-write stencil. Enzyme is about 3.5% faster on the
taped nonlinear recurrence. These figures apply to those workloads and toolchains
only.

An earlier comparison on VMEC++ found hand-written Fortran derivatives 1.5 to 1.9
times slower than C++/Enzyme, which ruled out a general performance claim. Since
then, performance is stated per workload and only with a measurement behind it; see
the [performance gate record](design/go-no-go.md). Where another AD tool measures
faster for a given workload, that tool is the better choice for it.
